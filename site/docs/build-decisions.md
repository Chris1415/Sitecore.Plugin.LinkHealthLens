# Build decisions — Link Health Lens

Component-grained decision record (rule 87). Not `docs/decisions.md` (the ADR index, regenerated by `/document`).

## T005 — ClientSDK init pattern

Kept the scaffold's **Provider pattern** (`components/providers/marketplace.tsx`, React Context) rather than
switching to the singleton pattern from `marketplace-sdk-client` § 2. Reason: the whole app is one route
consumed entirely inside React (`/pages-context`); the singleton pattern exists for non-React consumers,
which this app has none of. Modules registered: `[XMC]` only — no `AI` module, this app makes no AI-skills
calls.

## T005 — root `/` route behaviour

Root `/` was left as the scaffold's demo page (`application.context` + `listLanguages` examples), not
redirected or 404'd. Rationale: ADR-0004 fixes the app to exactly one *registered* extension point
(`xmc:pages:contextpanel` @ `/pages-context`) — the root route is never bound in App Studio and is not part
of the app's registered surface, so what it shows is inert. Keeping the demo costs nothing and gives a
cheap local sanity check that `application.context` resolves outside the Pages canvas too. Revisit if this
reads as confusing during code review.
